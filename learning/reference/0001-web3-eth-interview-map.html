Web3 / ETH 面试知识地图

围绕 eth-fund-trace 的学习顺序与最低掌握标准。

层次必须掌握项目落点最低面试标准
1. 账本与共识账户状态、区块、PoS、链头、safe/finalized、reorgsafe head、同步区间、跨链确认解释“已上链”和“最终确定”的区别
2. 交易与 EVMEOA/contract、nonce、gas、calldata、ABI、revert、receipttransactionanalysis、chainrpc从签名交易讲到 logs 和状态变化
3. Token 标准ERC-20、allowance、Transfer/Approval、decimals、WETHtokentx、ReceiptTransfer、WrapEvent解释 ETH 与 ERC-20 数据来源为何不同
4. 链上数据工程RPC vs indexer、分页、限流、幂等、重试、检查点、reorgetherscan、syncer、store解释为什么同步是异步且可恢复的
5. 图追踪BFS、方向、深度、Top-N、终点、游标、数据完整度tracer、fundgraph给出复杂度并说明高频节点风险
6. DeFiAMM、x*y=k、V3 集中流动性、Router/Pool、slippage、MEVUniswap V3 分析从 receipt 证据解释实际成交而非 calldata 意图
7. L2 与桥rollup、sequencer、L1 data、deposit、withdrawal、challenge periodEthereum/Base bridge解释跨链状态机和两侧证据
8. 风险与安全私钥、签名、approval、重放、RPC 信任、标签证据、误报risk、profile、labels区分事实、规则判断和身份结论
9. 系统设计缓存、批处理、索引、背压、并发、可观测性、成本Go worker、MongoDB、React Query能提出有界追踪和生产化路线

推荐课程顺序

  1. 从链上交易到资金图：证据模型与端到端链路
  2. EVM 执行现场：gas、ABI、calldata、logs、revert
  3. 第二课补充：三笔真实交易、函数字典与地址角色
  4. 链上数据工程：RPC、Indexer、reorg、幂等和检查点
  5. 资金图算法：BFS、Top-N、复杂度和高频节点治理
  6. Uniswap V3：从 Router 意图到 Pool 成交证据
  7. Base / OP Stack：rollup、最终性和官方桥状态机
  8. 风险画像：规则版本、证据等级、误报与不可归因性
  9. 项目答辩：5 分钟陈述、系统设计追问和故障场景
贯穿原则：永远区分链上事实、协议解释、启发式推断和确定性身份标签。面试中能够主动声明证据等级，通常比多背十个术语更有价值。
