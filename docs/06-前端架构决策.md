# 前端架构决策

## 当前决策

| 主题 | 选择 |
| --- | --- |
| 图引擎 | React Flow + ELK layered |
| 网络 | 固定 Ethereum，选择器只读 |
| 空间语义 | 种子居中，上游在左、下游在右 |
| 扩展 | 初始图按需加载，节点按钮手动扩展上游或下游 |
| 深度 | 前端不按 5 跳过滤，已返回节点全部可见 |
| Swap | 一次交换显示为双向关系 |
| 桥 | 只显示跨链桥终点，不显示桥接边或目标链 |
| 风险 | 只显示查询地址的直接标签风险 |
| 金额 | 全程保留原始整数字符串，渲染时按 decimals 格式化 |
| 部署 | Vite 构建后由 Go 同源托管 |

## 图数据规则

节点 ID 使用 `chain:lowercaseAddress`，当前 chain 固定为 `ethereum`。布局根据有符号深度放置节点，但不使用深度过滤可见性。

前端直接使用后端 `TraceEdge`，不按金额或时间猜测额外关系。手动扩展成功后将扩展任务中的节点、边、标签和语义证据合并到当前图；无新增边时显示明确终点或失败状态，不能只让画面跳动。

## 状态与版本

前端只接受 `trace-v1`。旧版本不做兼容渲染，提示重新执行。Trace 和扩展任务通过可取消轮询读取；用户停止任务时同时停止当前依赖同步。

Base 泳道、桥分析面板、风险传播任务和标签传染展示已删除。
